# Testing

## 1. Purpose

This folder contains testing documentation and records for the Automatic Fire Extinguisher System project.

The initial testing focuses on the ESP32-based electronic prototype, including sensor readings, simulated output, and basic fault handling.

## 2. Testing Documentation

The testing resources may include:

- Test procedures
- Sensor reading records
- Test case results
- Observed problems and fixes
- Future validation notes

## 3. Test Results

Actual results should be recorded in `sensor-test-results.md`.

Each test record should include:

- Test date
- Hardware and sensor configuration
- Test conditions
- Observed readings
- Expected and actual behaviour
- Pass, fail, or pending status
- Notes about any problems

Do not record a test as successful until it has actually been performed.

## 4. Safety

Initial testing must use safe electronic simulation. Keep real suppression cartridges and activation mechanisms disconnected from the prototype.

Do not perform uncontrolled fire tests or use homemade circuits to activate suppression equipment.

## 5. Current Status

Testing documentation is being developed. Actual test results and validation status must be updated as testing is completed.

Successful electronic prototype tests do not establish that the system is a certified fire detection or suppression product.
